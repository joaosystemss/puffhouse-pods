# Puff House Pods

Site institucional desenvolvido para a **Puff House Pods**, com foco em apresentação da marca, produtos e experiência de navegação moderna e responsiva.

## 🚀 Sobre o projeto

O Puff House Pods é um projeto web desenvolvido para apresentar a identidade da marca e seus produtos de forma moderna, rápida e responsiva.

O projeto foi desenvolvido utilizando tecnologias modernas do ecossistema Front-end.

## ✨ Funcionalidades

* Interface moderna e responsiva
* Apresentação de produtos
* Navegação otimizada
* Design adaptado para desktop e dispositivos móveis
* Estrutura organizada e componentizada
* Performance otimizada

## 🛠️ Tecnologias

* React
* TypeScript
* Vite
* Tailwind CSS
* JavaScript
* HTML5
* CSS3

## 💻 Como executar

Clone o repositório:

```bash
git clone https://github.com/joaosystemss/puffhouse-pods.git
```

Entre na pasta:

```bash
cd puffhouse-pods
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

O projeto estará disponível localmente no endereço indicado pelo Vite.
